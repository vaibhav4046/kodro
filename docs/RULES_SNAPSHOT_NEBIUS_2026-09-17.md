# Nebius x NVIDIA hackathon — rules snapshot (2026-09-17)

Source: https://nebiusglobalaihackathon.devpost.com/rules (fetched 2026-09-17).
Official rules override this file if they change.

- Submission period: 2026-08-26 09:00 PDT → **2026-10-30 10:00 PDT**.
- Judging Dec 1–15, 2026; winners ~Jan 11, 2027. 6,950 participants at snapshot time.
- Hard requirements: working app that **runs on Nebius Token Factory or
  Nebius AI Cloud** (runtime call to the Token Factory inference API, or
  deploy/run on Serverless Jobs/Endpoints/DevPods) **and uses ≥1 NVIDIA
  open-source model**; fits one track.
- Tracks: Coding & Agentic Engineering · Best Apps & Agents · Personal AI ·
  **Physical AI** (Kodro's track: Nemotron/GROOT/Cosmos/Sonic, Serverless
  Jobs for sim/synthetic-data/policy-eval; demo video needs ≥1 min of key
  modules in action when no physical hardware).
- Submission: working demo URL (not required for Physical AI), text
  description, **public repo + OSI license + README setup/run instructions**,
  **video <3 min on YouTube**, track choice, Token Factory/NVIDIA feedback,
  and — for pre-existing projects — a **written explanation of significant
  updates during the period** (`CHANGELOG_HACKATHON.md`).
- Stage 1 pass/fail (theme fit + real API/SDK use, no superficial rebrand);
  Stage 2 equal weights: Technological Implementation, Design, Potential
  Impact, Quality of Idea. Tie-breaks cascade from the first criterion.
- Prizes: $20k/$10k/$6k overall; Jetson Orin Nano per track; $3k Tavily
  bonus (functional runtime Tavily call); $500 city awards; feedback awards.
  One Overall OR one Track + one Bonus per project.
- Credits path (Resources page, same date): $25 Token Factory credits via
  form (code `NEBIUS-DEVPOST-GLOBAL26`); more (Token Factory, Tavily,
  Academy) via the free Nebius Builders Program. **No credits have been
  claimed from this environment; no Nebius account action was taken here.**

Chosen track: **Physical AI**. Tavily bonus: optional, only if genuinely
useful (undecided; no Tavily code exists — verified zero repo matches).
