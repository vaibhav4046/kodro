# Kodro first lesson card

## Read this five minutes before the class

### The outcome

Pupils will change one line of Python, predict what the change will do, run the
rover and explain the result.

Use **Drive to the Flag** for a gentle first session. The goal is to make the
rover travel 3 metres without a collision.

### Before pupils arrive

- Open Kodro on one pupil device.
- From the front page choose **Learn to code**.
- Open **Drive to the Flag**.
- Press **Run** once and check that the rover moves.
- If the 3D view is slow, choose the 2.5D view or set render quality to Low.
- Decide whether pupils will work alone or in driver and navigator pairs.

The hosted page needs internet for its first load. A cached copy can then work
offline. A local or desktop copy does not need an account or class server.

### Put this on the board

```text
1. Predict
2. Change one thing
3. Run
4. Read the goal feedback
5. Explain what happened
```

### A 45-minute lesson

| Time | Teacher | Pupils |
| ---: | --- | --- |
| 0 to 5 min | Show Learn to code, the lesson goal and the Run button. | Find the lesson and keep the starter unchanged. |
| 5 to 10 min | Run `move_forward(1)` and ask where the rover will stop. | Predict before watching. |
| 10 to 25 min | Ask for one change at a time. Avoid giving the answer. | Change the number or add a line, then run and read feedback. |
| 25 to 35 min | Ask pairs to compare two working programs. | Explain how both programs reach the same distance. |
| 35 to 42 min | Model one bug, such as a misspelled function or missing bracket. | Find and correct the bug. |
| 42 to 45 min | Ask for the meaning of program and sequence. | Give one sentence each. |

### Questions to ask

- Which line runs first?
- What do you predict before we press Run?
- What changed on screen?
- Did the goal feedback match what you saw?
- Can you solve it a different way?
- How do you know the rover travelled far enough?

### If a pupil is stuck

1. Ask them to read the first unmet goal.
2. Ask them to point to the number that controls distance.
3. Ask them to change only that number.
4. Use the lesson hints one at a time.
5. After the hints are exhausted, use the worked answer as a trace example.

Do not make a pupil wait with no route forward. Reading and tracing a worked
program is a normal part of learning to code.

### Finish with evidence

Collect one of these:

- a route sketch with the predicted stopping point;
- the final program file;
- one sentence explaining the effect of the changed number;
- a verbal line-by-line trace.

The in-app score is practice feedback, not assessment evidence.

### Safety and honesty

Kodro is a kinematic simulation for learning and early design comparison. It
does not certify electrical safety, mechanical fit or real robot behaviour.
Nothing in this first lesson requires an AI model, account or external service.
