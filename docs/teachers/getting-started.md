# Getting started (teachers)

This page is the 10-minute walk-through every teacher should read first.
Full content lands in Task 20 of the build plan.

## Install

| Platform | Steps |
| --- | --- |
| Windows | Download the latest `Kodro-windows.exe` from the releases page, double-click to run. No admin rights required. |
| macOS | Download `RoboLearn-macos.dmg`, drag the app into Applications. |
| Linux | `pip install robolearn && python -m robolearn` |

## First-run wizard

The first time you launch RoboLearn it asks four short questions: your
display name, your age band, your key stage, and the terrain you'd like to
start on. Everything stays on the local machine — no account, no internet,
no telemetry.
