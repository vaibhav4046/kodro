Two agents work in this repository at the same time: an ENGINE track and a
DESIGN track. This file is the contract that stops them destroying each other's
work.

## bundle.js

Generated by `node scripts/build_web.cjs`. Never hand-edited. It will conflict on
almost every pull, because both tracks edit sources that compile into it.

Resolution is always the same: take either side, rerun the build, commit the
rebuilt file. There is no meaning in its diff.

## If you need a change in a file you do not own

Do not make it. Append it to `docs/design/REQUESTS.md` with the file, the exact
change and the reason. The owner applies it.

## Git rhythm

```
git pull --rebase origin main
node scripts/build_web.cjs
git add -A && git commit -m "..." && git push
```

Every 30 to 45 minutes. A single large end-of-night commit cannot be merged.
