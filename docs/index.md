# RoboLearn

> A free, offline Python desktop simulator that teaches the UK Computing
> National Curriculum through procedural pupil code that drives a virtual
> rover across Earth, Mars, underwater and space terrains.

## What you get

- A tiny, readable [pupil-facing API](pupils/api-cheatsheet.md): `move_forward`,
  `turn_left`, `read_distance`, `collect_sample`, …
- Ten lessons mapped to KS3 and KS4 programme-of-study items.
- A self-improving memory layer that adapts difficulty per pupil.
- A teacher dashboard with class-wide strengths and weaknesses.
- A time-travel debugger that replays any submission frame by frame.
